# 🌱 Smart Agriculture AI

An AI-powered agriculture assistant that helps farmers with crop recommendation,
crop yield prediction, plant disease detection, irrigation recommendation,
fertilizer recommendation, weather analysis and an AI agriculture chatbot.

## ✨ Features

### 🌾 Crop Recommendation
Recommends suitable crops based on soil and environmental conditions.

### 📊 Crop Yield Prediction
Predicts expected agricultural crop yield using machine learning.

### 🍃 Plant Disease Detection
Uses a 38-class PlantVillage-trained MobileNetV2 model to identify plant diseases.

### 💧 Irrigation Recommendation
Predicts irrigation requirements as Low, Medium or High.

### 🧪 Fertilizer Recommendation
Recommends suitable fertilizer based on soil nutrient conditions.

### 🌦️ Weather Analysis
Provides current weather information and farming advisory.

### 🤖 Agriculture AI Chatbot
Provides agriculture-related assistance using an NVIDIA-hosted LLM.
