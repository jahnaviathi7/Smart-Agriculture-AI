# 🌱 Smart Agriculture AI

## 📌 Project Overview

Smart Agriculture AI is an AI and Machine Learning based agriculture assistance system designed to help farmers make better decisions using data-driven recommendations.

The project provides multiple agricultural modules including crop recommendation, crop yield prediction, irrigation recommendation, fertilizer recommendation, weather analysis, plant disease detection, and an AI-based agriculture chatbot.

---

## 🚀 Features

* 🌾 Crop Recommendation
* 📊 Crop Yield Prediction
* 💧 Irrigation Recommendation
* 🧪 Fertilizer Recommendation
* 🌦️ Weather Analysis
* 🍃 Plant Disease Detection
* 🤖 Agriculture AI Chatbot
* 📚 RAG Knowledge Assistant
* 📈 Farmer Dashboard

## 📂 Project Modules

### 1. Crop Recommendation

Recommends suitable crops based on agricultural and environmental parameters.

### 2. Crop Yield Prediction

Predicts the expected crop yield using machine learning techniques.

### 3. Irrigation Recommendation

Provides irrigation recommendations based on soil and environmental conditions.

### 4. Fertilizer Recommendation

Recommends suitable fertilizers based on crop and soil-related parameters.

### 5. Weather Analysis

Analyzes weather information to support agricultural decision-making.

### 6. Plant Disease Detection

Detects plant diseases from plant leaf images using machine learning/deep learning techniques.

### 7. Agriculture AI Chatbot

Provides AI-based assistance for agriculture-related questions and farming guidance.

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd Smart-Agriculture-AI
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment:

```bash
venv\Scripts\activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

Run the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your default web browser.
